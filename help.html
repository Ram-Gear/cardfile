What Cardfile does

Ask Grok about this

Cardfile is Ram-Gear's web card file for customer and shop records, modelled on the classic Windows Cardfile. Each card has a one-line index line (up to 39 characters) and free text below it. Cards are grouped into card files (categories) that you choose from the File: picker.

You sign in with your QC Form username and PIN. The built-in Customers file is always shared with QC, and any other file can be shared with QC too, so it stays in sync on every device. Cardfile can also import and export classic .CRD files, and it can read a business card from a photo.

Sign-in screen

Ask Grok about this

When you are signed out, no cards are shown. Type your QC Username and PIN and press Sign in (or Enter). These are the same details you use in the QC app.

If your account has no Cardfile access, the screen says “You don’t have Cardfile access yet. Ask a QC admin to give you Cardfile access, then sign in again.” Use Sign in as someone else or Sign out.

Card view

Ask Grok about this

This view shows one card at a time, with the cards stacked behind it. The index line is at the top and the card text below it. Use the ◀ ▶ buttons or PgUp/PgDn to flip cards, or click a letter on the A–Z bar to jump to cards starting with that letter. Double-click the index line to edit it. The toolbar also has the scan (camera) button, the Sync with QC button and the search box. A chip shows whether the current file is shared with QC.

List view

Ask Grok about this

Choose View → List to see only the index lines, one per row. Click a row to select it, and type a letter to jump to the first card starting with that letter. Choose View → Card to go back. View → Fixed-width text lines up columns in the card text.

The scanner

Ask Grok about this

Press F8, choose Card → Scan business card…, or press the camera button. Then:

  1. Take photo (phone camera), Choose image… (a saved picture), or Use webcam and then Capture. You can also choose Type it in instead.
  2. Cardfile reads the text from the picture. If it’s sideways, use the rotate buttons to turn it and read it again. If reading fails, use Try again.
  3. Check the text and fields. If you fix the text, Re-read fields from text fills the fields again.
  4. Press Save card, or ← Rescan to start over.

Menus

Ask Grok about this

File

New card file…, Open… (Ctrl+O), Print and Print All, Import .CRD file(s)…, Export as .CRD (Cardfile 3.0), Export Backup (JSON), Restore Backup (JSON)…, Phone settings… (area code added to 7-digit numbers), Delete this card file…, and Reset (reload cards)…. When QC sync is on, the File menu also has Share with QC, Sync with QC now, Full resync with QC, and Sign in / Sign out of QC sync.

Edit

Undo (Ctrl+Z), Index… (F6, which edits the index line), and Restore (undoes all changes to the card in front since you brought it forward).

View

Card, List, and Fixed-width text.

Card

Add… (F7), Delete, Duplicate, Autodial (call)… (F5), and Scan business card… (F8).

Search

Go To… (F4, which finds the next card whose index line contains the text), Find… and Find Next (F3, which search the card text), and Search All Files… (Ctrl+Shift+F).

Keys and Commands (F1), User guide (this page), and About Cardfile….

Common tasks

Ask Grok about this

Add a card

  1. Choose the file in the File: picker.
  2. Press F7 (Card → Add…).
  3. Type the index line and press OK.
  4. Type the card text.

Find a card

  1. Type in the search box, or press Ctrl+Shift+F to search every file.
  2. Or press F4 to search index lines, or use Search → Find… to search card text, then F3 for the next match.

Call a customer

  1. Open the card.
  2. Press F5 (Autodial).
  3. Pick the number. If 7-digit numbers need an area code, set one in File → Phone settings….

Share a file with QC

  1. Choose the file.
  2. Choose File → Share with QC. The chip on the toolbar shows that it’s shared.

Bring in old Cardfile files

  1. Choose File → Import .CRD file(s)….
  2. Pick one or more .CRD files.

Make a backup

  1. Choose File → Export Backup (JSON).
  2. To bring it back later, choose File → Restore Backup (JSON)….

Undo a mistake

  1. Press Ctrl+Z (outside the card text) to undo the last card operation, or use Edit → Restore to undo every change to the card in front.

Roles

Ask Grok about this

A QC admin gives each person a Cardfile role:

RoleCan do
No accessSees no cards. Cards kept in the browser are cleared, and the sign-in screen asks you to get access from a QC admin.
ViewerRead, search, print, export and autodial. Can’t add, edit, scan, import or delete.
EditorEverything a viewer can do, plus add, edit, duplicate, scan and import cards. Can’t delete cards or card files.
AdminEverything, including deleting cards and card files.

If you try to delete something the server doesn’t allow, the card is put back.

    Troubleshooting

    Ask Grok about this

    • Sign-in fails: check your username and PIN in the QC app. They are the same.
    • “You don’t have Cardfile access yet”: ask a QC admin to give you Cardfile access, then sign in again.
    • A red sync message on the toolbar: click it to see the problem. Then try File → Sync with QC now, or File → Full resync with QC.
    • Can’t delete a Customers card: cards linked to a QC customer are removed in the QC app. The built-in Customers file can’t be deleted.
    • Menu items are greyed out or missing: your role may not allow them (see Roles).
    • The scanner can’t read a card: use good light and hold the camera flat, rotate the picture, fix the text and press Re-read fields, or choose Type it in instead.
    • Things look wrong in this browser: File → Reset (reload cards)… clears this browser and reloads. Cards and changes kept only in this browser are lost, and shared cards download again.
